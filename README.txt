# ShopEase – Frontend E-Commerce Website

## 1. Project Title and Brief Description

**Project Title:** ShopEase – Online E-Commerce Shopping Website

ShopEase is a frontend-based e-commerce website developed using HTML, CSS and JavaScript. It provides users with a simple online shopping experience where they can browse products, search for items, filter products by category, sort products and manage their shopping cart.

The application consists of four main pages: Home, Products, Cart and Checkout. It is deployed using GitHub Pages and can be accessed through a web browser.

## 2. Problem Statement and Objectives

### Problem Statement

Online shopping websites provide customers with a convenient way to explore and purchase products. A well-organized shopping interface is necessary to help users browse products, find required items and review their selections before checkout.

The objective of this project is to develop a simple and user-friendly e-commerce website that demonstrates the basic functionalities of an online shopping platform.

### Objectives

- To develop a user-friendly e-commerce website.
- To display products in an organized catalogue.
- To provide product search and category filtering.
- To implement product sorting functionality.
- To provide a shopping cart interface.
- To create a simple checkout and order confirmation interface.
- To deploy the website using GitHub Pages.

## 3. Features / Modules Implemented

The application consists of the following modules:

### 3.1 Home Page (index.html)
- Acts as the main entry point of the website.
- Provides navigation to different sections.
- Introduces the ShopEase shopping platform.

### 3.2 Product Catalogue (products.html)
- Displays available products.
- Provides product search functionality.
- Allows users to filter products by category.
- Supports sorting of products.

### 3.3 Shopping Cart (cart.html)
- Provides an interface to review selected products.
- Displays shopping cart information.
- Allows users to proceed towards checkout.

### 3.4 Checkout (checkout.html)
- Provides a checkout interface.
- Displays the order confirmation flow.
- Demonstrates the final stage of the shopping process.

### 3.5 JavaScript Functionality (script.js)
- Handles client-side interactions.
- Supports interactive website functionality.

### 3.6 Styling (style.css)
- Defines the appearance of the website.
- Controls layout, colours, spacing and styling.
- Provides a consistent design across the pages.

## 5. Prerequisites and Installation Steps

### Prerequisites

- A computer with Windows, Linux or macOS.
- A modern web browser (Google Chrome, Microsoft Edge, etc.).
- Visual Studio Code or any text editor.
- Internet connection for accessing the deployed website.

### Installation Steps

1. Open the GitHub repository:

   https://github.com/MRS-Sweta/E-Commerce-App

2. Click the green **Code** button.

3. Select **Download ZIP**.

4. Extract the downloaded ZIP file.

5. Open the extracted project folder using Visual Studio Code.

6. Verify that the following files are present:

   - README.txt
   - index.html
   - products.html
   - cart.html
   - checkout.html
   - script.js
   - style.css

## 6. Instructions to Run the Application

### Method 1: Run Locally

1. Open the project folder.
2. Locate the `index.html` file.
3. Double-click the file to open it in a web browser.
4. Alternatively, use the Live Server extension in Visual Studio Code.
5. Navigate through the website using its navigation options.

### Method 2: Access the Deployed Application

The application is deployed using GitHub Pages.

**Live Website:**

https://mrs-sweta.github.io/E-Commerce-App/

Open the above link in a web browser to access the application directly without installing any additional software.

## 10. Known Limitations and Possible Future Enhancements

### Known Limitations

- The application is frontend-only.
- No backend server is connected.
- No database is used for permanent data storage.
- User authentication is not implemented.
- Real payment processing is not supported.
- Product and order information is not managed through a server.

### Possible Future Enhancements

- Integrate a backend server for handling orders.
- Add a database to store product and customer information.
- Implement user registration and login.
- Integrate a secure online payment gateway.
- Add an order tracking system.
- Develop an administrator dashboard for product management.
- Improve mobile responsiveness and accessibility.

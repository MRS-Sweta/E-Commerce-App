SHOPEASE - FRONTEND E-COMMERCE DEMO

Contents:
- index.html: Home page
- products.html: Product catalogue, search, category filter and sorting
- cart.html: Shopping cart
- checkout.html: Demo checkout and confirmation
- style.css: Responsive styling
- script.js: Product data and browser-side functionality

HOW TO RUN:
1. Extract the ZIP file.
2. Open the ShopEase folder in VS Code.
3. Open index.html in a browser, or use the VS Code Live Server extension.
4. Browse products and test Add to Cart, quantity changes and demo checkout.

NOTES:
- This is a frontend-only assignment project.
- Product data is stored in JavaScript.
- Cart data is stored in browser localStorage.
- No backend, database or real payment processing is included.
- The Google Fonts import requires an internet connection; the site has fallback fonts.
